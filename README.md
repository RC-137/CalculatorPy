# CalculatorPy (Python + HTML/CSS)

A simple **desktop calculator** built using **Python** and **HTML/CSS** with `pywebview`.  
It supports basic arithmetic operations (`+`, `-`, `*`, `/`) and decimal numbers.

---

## Features

- Addition, subtraction, multiplication, division
- Decimal support (prevents multiple decimals in a single number)
- Clear button (`C`)
- Trailing decimal handled automatically
- Simple, modern interface with responsive buttons

---

## Requirements

- Python 3.7+
- `pywebview` library

Install `pywebview` via pip if not already installed:

```bash
pip install pywebview
